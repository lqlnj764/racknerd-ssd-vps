## 买 SSD VPS 之前，先看三处：盘的类型、虚拟化、续费价

SSD VPS 指的是把虚拟机磁盘放在固态硬盘上的 VPS。同样是 "SSD" 三个字母，背后可能是三种东西：真 NVMe、SATA SSD，或者机械盘加一层 SSD 缓存。速度差距很具体：主流 NVMe 读取在 3,500–7,000 MB/s，SATA SSD 约 550 MB/s，延迟从 50–60 微秒降到 10–20 微秒。挂博客、跑网站，SATA SSD 和 NVMe 的体感差距有限；数据库读写密集的场景，这个差距会直接写进响应时间里。

第二处看虚拟化。KVM 是完全虚拟化，能自己换内核、跑 Docker、挂 ISO 装系统；OpenVZ、LXC 这类容器方案共享宿主机内核，便宜但限制多。RackNerd 全线 KVM，在同价位里算厚道的一点。

第三处最容易被忽略：续费价。把首购价和续费价分开看，很多“低价”会当场现形。这笔账下面有具体数字。

## SSD VPS 常见问题

不会。年付促销价到期后按同价续费，这是它在低价 VPS 圈里被反复推荐的主要原因。

### SSD 和 NVMe 的差距，日常用能感觉到吗？

挂网站、跑博客基本感觉不到；数据库、频繁编译、大量小文件读写的场景，NVMe 的低延迟能明显缩短响应时间。按 RackNerd 的价格，用 SSD 换低价这笔账是成立的；真要顶配磁盘性能，可以直接看 IONOS、Contabo 这类已全线切换 NVMe 的月付厂商。

### 1GB 内存的套餐够用吗？

静态站、轻博客、一两个脚本够用。要 Docker 加数据库同机跑，1GB 很快见底，从 2.5GB 起步更稳。

### 能装 Windows 吗？

系统模板以 Linux 为主，Windows 需要额外的授权成本，而且 1–2.5GB 内存跑 Windows 体验很差，这个价位就别指望了。
